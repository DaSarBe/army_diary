# 第三輪複查（PR #8，commit fdb5963）：第 2 關複查 + 第 3 關稜線哨所

## 第 2 關複查
我上次提的都有改：小林陣亡版、阿凱留車上、復電可選、駕駛三版本 chatter、復電版與摸黑版的 radar_complete 都在，pickStory 路由也對。剩下三個小問題：

1. **戰後才復電，結尾台詞不對。** `radar_complete` 只看 `isl_power_restored`，戰後才復電（只設 late）會播「你全程沒開燈，這很不容易」，但玩家其實去開過燈。建議加 `radar_complete_late`：
   - 黃連長：「雷達站拿回來了。燈是打完才開的，不過線路圖你看到了。下一目標稜線哨所。先休息。」
   （阿凱留車上的版本再接「阿凱：我在車上等你們。燈亮了沒有？」）
2. **小林陣亡時，弱訊號被忽略。** `radar_door` 在 linDown 時直接回 `radar_door_missing`，不管 `isl_radio_weak`。天線選擇是第 1 關的重要選擇，弱訊號時黃連長應該一樣雜訊。建議加 `radar_door_missing_weak`：
   - 阿凱：「整區沒電。」
   - 黃連長：「……配電箱……機房……聽得到嗎。」
3. **阿凱留車上時，`power_hint` 仍由小林說**，沒有問題；但 `radar_complete_outside` 的阿凱無線電台詞，在天線弱訊號時應帶雜訊，不然連長雜訊、阿凱清楚，不自然。可略，優先度低。

## 第 3 關：問題與替換

### 必修
1. **機車段 chatter 和戰後台詞一字不差重複。** `vehicle_ridge.chatter`（阿凱「這台只有一個座位。那我坐你背上。」小林「你想害我們翻車嗎？」）和 `ridge_outro_bike` 同樣三句。玩家在機車上聽一次，到哨所又聽一次。保留戰後那段（outline 的設計，笑點在到達後），把上車時的 chatter 換掉：
   - `vehicle_ridge.chatter`：
     - 黃連長：「聲音太大了。對方聽得到。」
     - 小林：「我們腳程跟不上。你先走，我跟阿凱走岩石。」
   - `vehicle_ridge_missing.chatter`：
     - 黃連長：「聲音太大了。對方聽得到。」
     - 阿凱：「我跟不上。你先走，我走小路。」
2. **`ridge_outro_bike_missing` 的黃連長「坐好。下一目標坑道。」** 沒人要他坐好，這時人已經到了。改：
   - 黃連長：「你騎得很吵，但你到了。下一目標坑道。」
3. **outline 的小林指引缺了。** 無線電品質好時小林要報「左邊那塊石頭後面有人」，現在 `ridge_callout` 只有 hint，沒有對白。建議戰鬥中紅點第一次亮起後，toast：
   - 好訊號：小林：「左邊那塊石頭後面有人。」
   - 弱訊號：電台只有雜訊，不播（這就是差別）。
   - 小林陣亡：不播（不要由阿凱代替，這是通信兵才報得出的位置）。
   - 之後紅點亮起時**不要再播任何對白**，這是整款遊戲最安靜的一秒。

### 建議修
4. **「下一目標坑道／下一程救人」說了三次。** `outpost_roster` 黃連長「下一程我們去找他」、`ridge_outro_*` 的「下一目標坑道」、`ridge_complete`「王班長在坑道。下一程救人。」。留第一次（情緒最強），後兩處改：
   - `ridge_outro_walk` 黃連長：「先把水喝完。」
   - `ridge_outro_bike_missing` 黃連長：「你騎得很吵，但你到了。」
   - `ridge_complete`：黃連長：「稜線過了。」電台：「收到。」
5. **`outpost_roster_missing` 阿凱念點名單的語氣太平。** 小林陣亡後，王班長是阿凱此刻唯一還活著的線索，應該有一點情緒：
   - 阿凱：「點名單。王班長後面寫……俘。不是亡。」
   - 阿凱：「他不是亡的。」
   - 黃連長：「還活著。被送去坑道。」
6. **`ridge_rest_quiet`（阿凱陣亡版）和 `ridge_rest_missing` 沒有同時成立的版本。** 小林和阿凱都陣亡時，會播 `ridge_rest_missing`，阿凱還在說話。第 3 關起阿凱的生死才判定，所以只有重試時會遇到；建議加 `ridge_rest_alone`：
   - 黃連長：「稜線腳下。前面有人在看你。」
   - 黃連長：「頻道裡只剩我了。我陪你走。」
7. **`scout_choice` 之後沒有任何收尾，這是對的**，outline 就是不評價。不過玩家選完後會直接進 `ridge_outro`，節奏很突兀。建議在選項後用一個沒有台詞的 1.5 秒黑場或風聲，再接收尾，不要加對白。

- 吉普車第 3 關沒有出現，符合「路太窄」。
- `ridge_approach` 的小林版與連長版（陣亡）語氣一致。
