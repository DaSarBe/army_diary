> 世界觀：《阿兵哥日記》。第一人稱射擊，電腦與手機。
> 對齊檔案：`/workspace/army-diary/data/island-fps-system.json`（Dai 負責所有數值與機率）。
> **本大綱沒有數值。** 數量、傷害、機率、時間一律以 island-fps-system.json 為準，這裡只用文字描述。
> 敵人一律稱「**不明敵軍**」，不寫國名。陣亡一律用**黑畫面加無線電音訊**，沒有血腥畫面。
> 篇幅不設上限，以劇情流暢為優先。

## 1. 主角

- **姓名：** 方子豪（暫名）。玩家可在開場輸入名字，班長與同袍多半叫他「老方」。
- **背景：** 三十出頭，退伍已經十年。步兵役畢業，現在是南部的水電行師傅，平常修配電箱和抽水馬達。
  - 這讓**雷達站停電**有合理的切入點：他看得懂配電箱、備用發電機和接線。
  - 他留著當年的肌肉記憶：T91 的分解結合、基本的掩體動作。他也騎過機車，因為水電行的工作用車就是一台舊機車。
- **為什麼被召回：** 離島守備部隊在一夜之間與本島失去大半聯絡。後備部隊接到**臨時動員令**，他被編進「島嶼收復支隊」。
  召集令上只有一句理由：「熟悉該型裝備、居住地距離登船點近。」
  他不是英雄，只是剛好在名單上，而且知道怎麼把槍拿好。
- **私人理由：** 失聯的人裡有王班長，他當年下部隊時的班長。這讓他有個「去找人」的理由，而不只是「去奪回據點」。

## 2. 全局故事線（一頁版）

臨時動員令下達，後備支隊乘夜登島。目標很單純：**一個據點一個據點奪回來，把無線電架起來，讓本島知道島上還有人。**
可是島上比想像中安靜，也更危險。每個據點都有一個不是只靠開槍就能解的難題：
灘頭要先站穩、雷達站沒電、稜線有狙擊、坑道裡有被俘的同袍、指揮所有一名指揮官。
最後的指揮所不是終點，而是讓玩家回頭看：**這一路你選擇了誰、放下了誰。**

語氣沿用《阿兵哥日記》：口語、帶點台式幽默，戰鬥橋段收斂，死亡不渲染，用沉默和無線電帶過。

## 4. 關卡（嚴格線性：1 → 2 → 3 → 4 → 5）

> 關卡 id 沿用 spec 的 `op1_landing` 到 `op5_hq`，**沒有重新命名**。
> 每關結構：**營區閒聊（輕鬆）→ 作戰（嚴肅）→ 轉場閒聊（輕鬆，可能在車上）**。
> 每關至少兩種打法，載具是其中一種。載具的規格全部引用 spec 的 `vehicles` 與 `props`。

### 關卡 1｜登陸灘頭（`op1_landing`）

- **目標：** 清空灘頭，架起無線電，讓第二批人員能上岸。
- **對應機制：** 教學：掩體與蹲下（沿用 fps-system.json 的 cover）。
- **載具：** **舢舨**（海上繞後，spec 已有）、**機車**（沿灘邊公路繞側翼，Dai 的建議）。
- **營區閒聊（上岸前，船艙裡）：** 後備軍人在登陸艇上互相比誰的肚子比較大。
  - 阿凱還沒登場，改由小林開場：他緊張得一直檢查同一條天線線頭。
  - 範例：小林：「老方，你有沒有覺得，我們的年紀比班長還大？」玩家可選一句回答，不影響劇情，只影響後面的關係台詞。
- **故事節奏：**
  1. 夜裡的登陸，海面很黑，只有引擎聲。
  2. 灘頭有舊碉堡和漁港。小林要找地方架天線。
  3. 黃連長的聲音只在無線電裡出現：「不要急，先站穩。」
  4. 清完灘頭，天線架好，本島第一次回應：「收到，請稍候。」
- **關鍵轉折：** 灘頭上沒有任何平民的痕跡，漁港的小船都被拖走了。有人先一步清過場。
- **打法選項：**
  - **正面推進：** 沿灘頭掩體一段一段壓上去。
  - **舢舨繞後：** 從海面摸到碉堡後面，開局少掉正面守軍，旗標 `isl_flank_by_sea`。被機槍手發現會翻船，要重新來過。
  - **機車繞側：** 沿灘邊的路快速切到側翼。**引擎聲會吸引附近敵人，所以潛行會失效**，這是一條「快但吵」的路線，不是潛行路線。旗標（提案）`isl_flank_by_bike`。
  - **潛行：** 沿礁岩與倉庫陰影，不騎車、不開船，用手上的近距離手段處理偵察兵。
- **影響結局的選擇：** 小林問：「天線要架在碉堡頂（訊號好但太顯眼），還是倉庫後面（安全但訊號弱）？」
  - 旗標 `isl_radio_strong` 或 `isl_radio_weak`，決定後面無線電支援與黃連長通話的品質。
- **轉場閒聊（上車前）：** 倉庫裡有一輛舊吉普車的殘骸，小林說：「這台修一修，說不定能開。」這是下一關吉普車的伏筆。

### 關卡 2｜雷達站（`op2_radar`）

- **目標：** 奪回雷達站機房，恢復站內電源與通訊。
- **對應機制：** 停電區：手電筒與能見度。
- **載具：** **吉普車**（前往雷達站途中遭遇敵人，Dai 的建議）、**發電機推車**（在站內當移動掩體，spec 已有）。
- **營區閒聊（出發前，修吉普車）：** 阿凱在這裡登場，一邊遞扳手一邊抱怨。
  - 範例：阿凱：「老方，你還活著喔？」「你胖了。」「你才胖。」
  - 他說他現在在賣保險，被召回的時候正在客戶家簽約。
  - 玩家可以選：讓阿凱開車、讓小林開車、自己開。這個選擇決定這一段路誰在副駕和機槍位，旗標 `isl_akai_with_you` 或 `isl_akai_outside`（後者代表阿凱留在車上接應）。
- **吉普車途中戰（前往雷達站的路上）：** 路上遇到一小隊不明敵軍的巡邏車。
  - 玩家可以當駕駛衝過去、當射手壓制，或下車步行繞過。
  - 吉普車裝有 T75 機槍，**連續開火會過熱**（數值見 spec）；車被打爆時所有人受傷並被甩出車外。
  - 這一段同時是「第一次體驗和 NPC 搭乘載具」的教學。
- **故事節奏：**
  1. 雷達站整區沒電，只有備用燈偶爾閃一下。手電筒會暴露位置。
  2. 玩家看得懂配電箱，可以中途**手動復電**，整層突然全亮。
  3. 機房角落有一把被拆下的 T75，繳獲。
- **關鍵轉折：** 配電箱的標籤被換過，是**本島**的備用線路圖，不是島上自己的。有人事先摸過這座雷達站，而且很懂。
- **打法選項：**
  - **摸黑潛行：** 不開手電、不復電，靠聲音與距離。
  - **復電強攻：** 復電後用 T75 壓制正面。旗標 `isl_power_restored`。
  - **推車前進：** 推著發電機推車當移動掩體往機房走（不能同時背人，不能衝刺）。
- **轉場閒聊（離開雷達站，吉普車上）：** 阿凱終於說出他怕黑的原因：小時候被關在雜物間。
  範例：阿凱：「你不准跟別人講。」「我只跟連長講。」「老方！」
  這一段完全是輕鬆的，作為進入稜線前的緩衝。

### 關卡 3｜稜線哨所（`op3_ridge`）

- **目標：** 穿過稜線，抵達哨所。
- **對應機制：** 狙擊紅點預警，蹲下可躲。
- **載具：** **機車**（沿稜線公路快速通過狙擊區，Dai 的建議）。吉普車這一關不使用（路太窄，這是劇情上的理由）。
- **營區閒聊（稜線腳下，短暫休息）：** 小林在調無線電，阿凱在啃一個冷掉的飯糰。
  - 範例：阿凱：「這個便當我吃過，味道像是上個月的。」
  - 黃連長在無線電裡只說一句：「前面有人在看你們。」
- **故事節奏：**
  1. 稜線上沒有遮蔽，風大，視野好，敵人的狙擊手也一樣。紅點亮起來的那一秒，是整個遊戲裡最安靜的一秒。
  2. 無線電裡小林指引：「左邊那塊石頭後面有人。」（無線電品質好時才有；差時只有雜訊。）
  3. 廢棄的**陸軍觀測哨**裡找到 T65K2 精準步槍。
  4. 哨所有一份點名單，王班長的名字被劃掉，後面寫著「俘」，不是「亡」。
- **關鍵轉折：** 王班長還活著，被送去坑道。玩家第一次有了明確的救人目標。
- **打法選項：**
  - **騎機車衝過去：** 速度快，但引擎聲會吸引敵人，而且機車只能用手槍反擊。旗標（提案）`isl_bike_dash`。
  - **走岩石步行：** 利用紅點預警與岩石掩護，一段一段推進。
  - **繞山腹小徑：** 路徑長，看不到狙擊紅點，遇到的是近戰衝鋒兵。
  - **用 T65K2 反狙：** 拿到精準步槍後回頭清掉狙擊手，之後的路就安全了。
- **影響結局的選擇：** 哨所裡有一個**受傷的敵軍斥候**，沒有武器，只有一部對講機。
  - 選項：補一槍、綁起來、放他走。沒有說明，不會立刻評價。
  - 旗標 `isl_spared_scout` 或 `isl_killed_scout`，後面指揮所的對話與結局會引用。
  - **呈現上沒有任何血腥畫面，也不強迫玩家選。**
- **轉場閒聊（機車停在哨所旁）：** 如果玩家騎了機車，阿凱會一直問「可不可以載我」。
  範例：阿凱：「這台只有一個座位。」「那我坐你背上。」「你想害我們翻車嗎？」
  若玩家沒騎車，改成阿凱在哨所裡翻出一包過期的餅乾。

### 關卡 4｜坑道（`op4_tunnel`）

- **目標：** 救出被俘同袍，背他撤離。
- **對應機制：** 近距離戰、背人撤退（沿用 carry 規則，含煙霧）。
- **載具：** **軌道車**（坑道內快速撤離，spec 已有）、**吉普車**（停在坑道外，載運被救的俘虜與王班長，Dai 的建議）。
- **營區閒聊（坑道口，上膛前）：** 這是全篇最安靜的一段。
  - 範例：小林：「老方，你有想過如果我們一起死在這，誰會先被發現嗎？」
  - 阿凱：「別講這個。我還沒簽完那張保單。」
  - 不開玩笑的人也不勉強自己開玩笑。語氣收斂，是為後面的戰鬥鋪墊。
- **故事節奏：**
  1. 坑道很窄，聲音被放大，敵人從岔路湧出來，是全篇最緊張的一關。
  2. 王班長被關在最深處，看到玩家第一句話：「你怎麼來了？我又沒叫你。」
  3. 他的腿受傷，要**背著他撤離**，還要在煙霧裡找出口。
  4. 若阿凱還在隊伍裡，他在後方放煙、擋住追兵。
- **關鍵轉折：** 坑道裡不只王班長，還有另外幾名被俘的島上守軍。背不動全部的人。
  - 核心取捨：**救誰、先救誰、要不要冒險回頭。**
  - 被俘守軍是**不可戰鬥的友軍**。誤傷會扣榮譽並記 `isl_friendly_fire`（Dai 的規格）。
- **打法選項：**
  - **潛入救人：** 避開巡邏，悄悄把王班長帶出來。
  - **強攻清場：** 清掉整條坑道，再從容撤離。
  - **軌道車撤離：** 最快，但**整座坑道的敵人會被驚動**，終點多一波衝鋒兵。旗標 `isl_rail_escape`，同時降低王班長陣亡機率（Dai 的規格）。
  - **吉普車接應：** 坑道外的吉普車可以載走王班長與全部被救的俘虜，車被打爆會讓車上所有人受傷。旗標（提案）`isl_jeep_convoy`。
- **影響結局的選擇：** 是否回頭救其他被俘守軍，還是直接帶著王班長撤離。
  - 旗標 `isl_wang_rescued`、`isl_captives_rescued`、`isl_captives_left`。
  - 王班長是否存活由表現決定（被擊中次數、煙霧、是否走軌道車），**第一次判定即為最終結果**。
- **轉場閒聊（吉普車上，離開坑道）：** 王班長坐在後座，一邊被包紮一邊罵人。
  範例：王班長：「誰教你們這樣開車的？我的屁股比腿還痛。」
  阿凱：「班長，你先坐好。」「我是在坐好啊！」
  若王班長陣亡，這一段改成沉默的車程，只有引擎聲和一段無線電裡的雜訊。

### 關卡 5｜島上指揮所（`op5_hq`）

- **目標：** 擊倒不明敵軍的指揮官。
- **對應機制：** Boss 戰，指揮官每損失一段血呼叫一波援兵。
- **載具：** **吉普車**（衝進指揮所前的廣場，Dai 的建議）。
- **營區閒聊（出發前，補給站）：** 全員難得坐在一起，像是臨時的部隊會餐。
  - 範例：王班長（若活著）：「打完這個，我請你們吃真正的便當，不是這種過期的。」
  - 阿凱：「班長說話算話？」「我什麼時候騙過你？」「上次你說三個月，結果是十二個月。」
  - 這是全篇最後一段輕鬆戲，之後只有戰鬥。
- **故事節奏：**
  1. 指揮所原本是島上守備部隊的中心，現在牆上貼的是別人的地圖。
  2. 黃連長在無線電裡：「這是最後一個了，打完我們就能回家。」（天線選擇影響通話品質。）
  3. 指揮官只說：「你們來得比預期早。」不報國名，不講理念。
  4. 倒下之後，玩家看到的是一間很普通的辦公室，桌上有一杯還沒涼的茶。
- **關鍵轉折：** 地圖上有別的據點標記，暗示這不是終點，只是第一階段結束。
- **打法選項：**
  - **吉普車衝廣場：** 吉普車衝進前廣場，用車載 T75 壓制外圍援兵。旗標（提案）`isl_jeep_charge`。
  - **正面強攻：** 下車一路打進指揮所，承受援兵。
  - **潛行斬首：** 利用先前的線索，從側門潛入，在援兵到來前壓制指揮官。
  - **精準壓制：** 用 T65K2 在山坡遠處壓制。
- **影響結局的選擇：** 是否**活捉**指揮官（需要之前沒殺斥候或無線電品質好等條件，具體由 Dai 定義）。
  - 旗標 `isl_commander_captured` 或 `isl_commander_killed`。

## 5. 結局與旗標

## 6. 死亡與重試（給 Sam、Dai）

- **主角倒下不是遊戲結束。** 一律從最近的存檔點重來（每據點開始與中途各一個），車輛狀態保留（spec 的 `checkpointKeepsVehicle`）。
- **同袍生死以第一次判定為準，重試洗不掉。**
  - 王班長、阿凱、小林的陣亡旗標，**在第一次判定當下寫入存檔**，之後讀檔或重試都不會重擲。
  - 就算玩家倒下後從存檔點重來，已經死去的人仍然是死去的。
- **劇情要保持一致：**
  - 若同袍的死亡發生在**玩家倒下之前**，重試時他不會再出現，營區閒聊與車上對話也改用「缺人版本」。
  - 若同袍的存活判定**尚未發生**（例如阿凱的判定在第 3 到 5 關期間），重試只會重打戰鬥，不會提前得知結果。
  - 重試時，已經播過的過場可以跳過，但**不會改成不同的版本**，避免玩家靠重試看出判定規則。
  - 黑畫面加無線電的死亡呈現在重試時**不會重播**，改成一行文字提示，避免每次重打都被重複打擊。
- **未決問題：** 玩家主角倒下是否要計入某個旗標（例如「倒下次數」）影響結局？目前**不計**，保持結局只看同袍與選擇。

## 7. 手機需求（給 Sam、Dai）

- **必須支援手機。** 版面參考決勝時刻，詳細按鍵配置與靈敏度以 spec 的 `mobile` 為準，由 Sam 與 Dai 負責。
- 劇情上的相關需求：
  1. **對話與閒聊要能在手機上順暢閱讀。** 單句不要太長，可以分段。
  2. **載具要有上下車按鈕。** 機車與吉普車的操作見 spec 的 `vehicles.*.controls`。
  3. **背人與救援要有明確的按鈕**，不需要精準操作。
  4. 手機上的潛行玩法（第 1、2、5 關）要確認操作可行，不行的話保留其他打法即可。

## 8. 《阿兵哥日記》連動（可選開關）

Tim 問「連動是什麼意思」：意思是玩家在《阿兵哥日記》第四章海灘戰裡做過的選擇與結果，是否影響這款遊戲的開場狀態。
這份大綱把它設計成**開關 `carryover`**，預設關閉。

### 情況 A：關閉（預設，兩款遊戲互相獨立）
- 主角是方子豪，同袍全部存活地登場，從頭開始。
- 開場文字：後備軍人召集令、水電行、登船。

### 情況 B：開啟（承接日記）
- 主角視為日記裡的玩家，十年後被召回。名字與背景沿用日記。
- 開場文字加一段：「十年前的那個海邊，你還記得嗎？」
- **Day-1 狀態變更對照：**

| 日記狀態 | 在本作第 1 天的影響 |
|---|---|
| `akai_kia` | 阿凱**不登場**，改由周學長（`npc_senior_chou`）頂替吉普車的駕駛位；營區閒聊加一段追思台詞 |
| `akai_injured` | 阿凱登場，走路有點跛，台詞提到當年的腳傷 |
| `sgt_wang_kia` | 王班長**不登場**；第 4 關被俘的核心人物改為島上老兵（`npc_island_old_guard`），並請 Dai 定義替代旗標（見下） |
| 王班長存活 | 照常登場，台詞提到當年的海灘 |
| `saved_civilian` | 開場回憶裡出現海邊阿伯，一句話帶過；不影響戰鬥 |
| `radio_fixed` | 小林開場一句：「那一分鐘我到現在都還記得」；第 1 關天線選項多一句提示 |
| `beach_hero` | 黃連長的無線電語氣多一份信任，開場多一句：「這次還是你。」 |
| `beach_fallback`、`court`、`hospitalized` | 只改台詞，不改任何屬性或結局條件 |

- **注意事項：**
  1. 日記裡的死亡**不會寫入 `isl_*` 陣亡旗標**，否則玩家一開場就接近「沉默的島」。日記死亡只改台詞與登場。
  2. 王班長在日記裡陣亡時，結局條件裡的 `isl_wang_rescued` 無法成立。建議 Dai 新增通用旗標 `isl_key_captive_rescued`（**提案**），讓「被救的核心人物」可以是王班長或老兵。
  3. 這一切**只改台詞與登場角色**，數值與機率不動，避免連動影響平衡。
